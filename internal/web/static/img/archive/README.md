# Retired icons

Icons that were replaced but kept in case they are wanted again. Each file is a standalone SVG (open it in a browser).

- `kind-*-outline.svg`: the outline unit-kind icons of the first unit-card design (bust, knight, wolf, troll, elephant).
  The cavalry knight was also the mount icon of the equipment list.
- `kind-*-v1.svg`: the very first, more abstract round (shield, horse, claws, horned face).
- `kind-infantry-soldier-filled.svg` and `kind-monster-troll-filled.svg`: the first filled set's infantry (a modern-looking
  soldier in a helmet) and monster (a troll) before they became a medieval great helm and a horned dragon.
- `kind-infantry-great-helm-filled.svg`, `kind-cavalry-horse-filled.svg`, `kind-beast-wolf-filled.svg`,
  `kind-monster-dragon-filled.svg` and `kind-monstrous-cavalry-oliphaunt-filled.svg`: our own filled silhouettes before the kind
  icons became game-icons.net icons. The horse head was also the mount icon of the equipment list.
- `role-hero-bar.svg`: the bar used as the insignia of a plain hero before it became a single chevron.

The icons in use are in `internal/web/templates/partials/units.gohtml`.
